# ⚡ 강원대학교 학과 맞춤형 & 통합 공지사항 AI 스마트 검색

강원대학교 포털의 **통합 공지사항(일반, 학사, 장학, 채용, 행사)**과 **내가 속한 학과의 전용 공지사항**을 한곳에 모아, **조사 및 추상어 제외 핵심어 탐색 ➔ AI 본문 문맥 심층 분석**의 2단계 파이프라인으로 찾아주는 Streamlit 기반 맞춤형 웹 애플리케이션입니다.

---

## 📌 주요 특징 및 기능

1. **🚫 추상적인 단어 배제 및 명확한 문서 일치 제약 (Strict Filtering)**
   - *"관심", "사랑", "참여", "노력", "희망"* 등 감정적이거나 상투적인 추상어는 검색 기준으로 채택하지 않습니다.
   - 공지사항 본문 끝에 흔히 들어가는 상투적 문구(*"학생 여러분의 많은 관심과 사랑 부탁드립니다"* 등)를 전처리로 완벽 제거(Denoising)하여 오매칭을 원천 차단합니다.
   - **제목이나 본문에 사용자의 실질 핵심 주제어가 실제로 명확하게 존재하는 공지만 추천**합니다.

2. **🧹 중복 공지 완전 박멸 (고유 글 ID 및 제목 정규화)**
   - 상단 고정 공지가 페이지별로 중복 수집되던 문제를 **고유 글 번호(`pstSn`, `articleNo`) 기준 정규화 URL**과 **정규화 제목 매칭**으로 100% 제거했습니다.

3. **📍 첫 화면: 학생용 vs 교수용 모드 분기 (전체 캠퍼스 다중 학과 지원)**
   - **👨‍🎓 학생용 모드**: 캠퍼스 ➔ 단과대학 ➔ 소속 학과(1개) 선택 및 직접 URL 입력 지원.
   - **👨‍🏫 교수용 모드**: 학생용과 동일한 직관적인 3단계 선택 UI(캠퍼스 ➔ 단과대학 ➔ 학과)를 유지하면서, `[➕ 선택한 학과 추가하기]` 및 `[➕ 단과대학 전체 학과 추가]` 버튼을 통해 **4️⃣ 추가된 학과 목록**에 자유롭게 누적 추가.
     - 춘천캠퍼스와 삼척·도계캠퍼스를 자유롭게 전환하며 여러 캠퍼스의 학과들을 4번 목록에 한곳에 모아 관리.
     - 4번 목록에서 개별 학과 바로가기 링크 및 `[삭제]` 기능 제공.
     - 선택한 여러 학과의 공지사항을 병렬(`ThreadPoolExecutor`)로 수집하여 포털 공지와 동시 통합 분석.

4. **👁️ 2개월 기본 기간 & 조회수 높은 순 초기 정렬**
   - 표시 기본 기간을 최근 2개월 전으로 최적화.
   - 검색어 입력 전 공지사항 목록을 **조회수가 높은 순(내림차순)**으로 나열하여 중요·인기 공지 우선 확인 가능.
   - 각 공지 카드에 `👁️ 조회수` 뱃지 표기.

4. **🎓 학과 공지사항 + 강원대 통합 공지사항 동시 크롤링**
   - 내가 선택한 학과의 최신 학과 공지와 학교 전체 공지사항을 통합 수집합니다.
   - 결과 목록에서 학과 공지는 `[📌 학과명]` 보라색 배지로 강조됩니다.

5. **🔍 [1단계] 조사·어미 제외 순수 핵심어 & 유사어 탐색**
   - 질문에서 불필요한 조사(-을/를, -에서, -으로 등)와 어미(-싶은데, -알려줘 등)를 정밀 제거하고 순수 명사 키워드만을 추출하여 동의어/연관어와 함께 탐색합니다.

6. **📑 본문 핵심 내용 자동 요약 (Summary)**
   - 검색 결과 각 공지사항에 대해 단순 청크 인용 대신, **질문 핵심어와 일정/대상/방법 등이 포함된 본문의 핵심 문맥 문장을 2~3줄로 정갈하게 자동 요약(`📑 본문 핵심 요약:`)**하여 바로 확인할 수 있습니다.

